The intent, in your words
INTENT 01Regular work

"Extremely simple, dispatching up a few things" — Hermes can do it, but via a sub-agent, never in the conductor's own session.

→ separate Hermes instance or a script
INTENT 02Standard work

"The usual command is fine" — OMP implements in a visible pane via /goal, then Droid reviews, fixes, and merges.

→ OMP primary · Droid review + merge
INTENT 03Critical work

"Difficult, needs a plan" — OMP plans in one instance, the plan transfers to a second OMP tab in the same worktree, implements /goal. Droid reviews & fixes.

→ OMP ×2 + Droid review lane
INTENT 04Merging

"Droid and Droid alone" — only after it has finished fixing whatever findings it found. Conductor never merges.

→ Droid exclusive · serialized

03Router readout — what route_task() decides

Three cards, one per lane, computed with the same signal logic as conductor_controller.py:route_task() — any critical signal → CRITICAL; else routine signals → ROUTINE; else STANDARD. This is what the conductor would dispatch.

ROUTINE
signals: docs-only · css-only · mechanical · tests-only (no critical signal)
Hermes sub-agent (separate instance, delegate_task)orplain script·headless, no pane required
risk routineworkerRole smolplanFirst falsereview false
delegate_task is the default for this lane since v1.7.0 — nothing else should touch it; any other harness here is over-routing.
STANDARD
signals: none of the above — the default bucket
OMP visible pane + worktree, implements /goal→Droid reviews→Droid merges
risk standardworkerRole taskplanFirst falsereview true
No alternate implementation harness is wired — OMP owns standard. Trivial variants may stay headless Hermes; the conductor records why when it picks the alternate.
CRITICAL
signals: security · schema/migration · external effect · multi-lane — any one flips it
OMP plans (tab 1)→plan handoff→OMP implements /goal (tab 2, same worktree)→Droid reviews→fixes→commits + merges
risk criticalworkerRole planplanFirst truereview true (Droid)
No alternate harness — critical stays OMP by intent: only OMP has the plan-handoff contract.
